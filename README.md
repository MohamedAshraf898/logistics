# Halden: logistics & factory demos

Single-file interactive 3D pages (Three.js + GSAP). No build step needed: open them in a browser or serve the folder.

- **`factory-twin.html`**: a factory digital twin with a live simulation and dashboards for manufacturing, QA & QC, purchasing & importing, inventory, sales, logistics & distribution, HR, finance and reports, plus a morning brief of the top 3 decisions. It opens in Arabic (right to left), and the EN/ع button switches to English.
- **`logistics-city.html`**: a scroll-driven isometric logistics city.
- **`index.html`**: a landing page linking both.

Run locally:

```bash
python3 -m http.server 8000
```

Then open http://localhost:8000.
